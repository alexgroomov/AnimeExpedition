# AnimeExpedition — Tower Macro

Клиентский макрос для обычных стадий, экспедиций, Tower и Regular Challenges. Профили и настройки сохраняются локально для каждого аккаунта, а загрузчик при запуске получает свежую версию из этого репозитория.

## Быстрый запуск

Выполни в Roblox одну строку:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/alexgroomov/AnimeExpedition/main/loader.lua?v=latest"))()
```

Для переходов между серверами включи **AUTO TP**. При первом запуске executor может попросить разрешение на загрузку файлов.

## Обычный макрос

1. Открой вкладку **MACRO** и **OPEN MACRO SETTINGS**.
2. Введи имя нового профиля и создай его.
3. Встань в нужное место, выставь камеру и нажми **SAVE START**.
4. Нажми **RECORD**, расставь и улучши юнитов, затем **STOP**.
5. Выбери профиль и нажми **RUN PROFILE**.

Макрос записывает клавиши `1–6`, `T` и клики. **REPEAT** повторяет профиль, а **Right Ctrl** скрывает или показывает окно.

Для рейдовых профилей включи **RAID REWARD DISMISS** в настройках MACRO. После завершения таймлайна макрос сделает не более двух редких кликов в безопасной области экрана, чтобы закрыть полноэкранную карточку выпавшего персонажа, и затем продолжит ждать **Repeat Stage**. Настройка сохраняется отдельно в выбранном профиле.

## Экспедиция

Во вкладке **EXPED.** используются отдельные профили:

- выбери слот юнита;
- **ADD PLACE** сохраняет его установку в выбранную точку;
- **ADD UPGRADE / UPGRADE MAX / ADD AUTO** добавляют нужное действие;
- **SAVE CAMERA** сохраняет рабочий ракурс;
- в настройках маршрута выбери приоритет награды;
- запусти последовательность.

Скрипт сам обрабатывает чекпоинты, карточки, карту маршрута, случайные Encounter-диалоги и повтор экспедиции.

## Tower

1. Сначала запиши обычный макрос для каждой нужной карты.
2. Во вкладке **TOWER** выбери карту.
3. На вкладке **MACRO** выбери соответствующий профиль и нажми **ASSIGN SELECTED MACRO** в Tower.
4. Нажми **START TOWER AUTO**.

После победы скрипт нажимает **Next Floor**, определяет следующую карту, выбирает назначенный профиль и продолжает, пока режим не будет остановлен.

## Auto Challenge

Открой **AUTO CHALLENGE SETTINGS**:

- включи нужные слоты Regular Challenge;
- назначь обычные профили каждой карте;
- выбери, куда возвращаться после челленджей: Event, Expedition или ожидание в лобби;
- при возврате в **Event** выбери **EVENT ACT: 1–3** и **EVENT PROFILE**: кнопка Act переключает одну из трёх карточек события, а Profile перебирает сохранённые профили MACRO;
- запусти автоматический режим.

Модификаторы **Shielded** и **Boss Waves** пропускаются, если для них нет подходящего профиля. Лимиты и текущий получасовой цикл сохраняются между телепортами.

После телепортов контроллер ждёт, пока нужный элемент интерфейса останется неподвижным 0,75 секунды. Переходы Challenge и Event подтверждаются появлением следующего меню; непринятый клик автоматически повторяется до трёх раз без постоянного фонового сканирования.

## Важно

- Профили хранятся в `TowerMacro_<ник>.json` и у каждого игрока свои.
- Для обновления достаточно снова запустить ту же строку загрузчика.
- Кнопка закрытия полностью останавливает текущую копию скрипта.
- Если интерфейс игры изменится после обновления, сначала останови автоматический режим и обнови загрузчик.
